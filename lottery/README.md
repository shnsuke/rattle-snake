# くじ引きアプリ（オフライン対応PWA）

スマホのブラウザで動く、ビルド不要のくじ引きアプリ。

## できること

- **オフラインで動く**: 一度開けば Service Worker がアプリ一式をキャッシュするので、以後は機内モードでも起動・抽選できる。ホーム画面に追加するとアプリのように使える。
- **人数をその都度決められる**（1〜200人）
- **選択肢の数をその都度決められる**（1〜30個）。名前も自由に変更可能。
  - 「本数を指定」ON: 選択肢ごとの本数を指定（例: 当たり1本・はずれ残り）。人数を変えると最後の選択肢で自動調整。
  - 「本数を指定」OFF: 人数を選択肢に均等に割り振る（チーム分け向け。余りの行き先もランダム）。
- 参加者の名前を入れると、カードに名前が表示される（空欄なら「1番」「2番」…）。
- カードをタップしてめくる／全部開く／結果一覧／同じ条件で引き直し。
- 乱数は `crypto.getRandomValues` を使った偏りのないシャッフル。
- 前回の設定は端末内（localStorage）に保存される。

## スマホで使う（GitHub Pages）

1. GitHub のリポジトリ → **Settings → Pages** を開く
2. Source を「Deploy from a branch」、Branch を公開したいブランチ・`/ (root)` にして Save
3. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/lottery/` をスマホで開く
4. 共有メニューから「ホーム画面に追加」（iPhone は Safari、Android は Chrome）
5. 以後はオフラインでも起動できる

## ファイル構成

```
index.html            画面
style.css             スタイル
app.js                設定・抽選ロジック
sw.js                 オフラインキャッシュ（Service Worker）
manifest.webmanifest  ホーム画面追加用
icon.svg              アイコン
```

更新を配布するときは `sw.js` の `CACHE_NAME` のバージョンを上げる。
